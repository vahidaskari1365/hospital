# بیمارستان تخصصی شفای نوین

وب‌سایت مدرن، سریع و قابل توسعه برای مجموعه بیمارستانی شفای نوین.

ساخته‌شده با **Next.js 16**، **TypeScript**، **Tailwind CSS 4**، **Prisma ORM** و **shadcn/ui**.

## ✨ ویژگی‌ها

- 🏥 صفحه اصلی مدرن و حرفه‌ای با انیمیشن‌های روان
- 👨‍⚕️ معرفی کامل بیمارستان، بخش‌ها، پزشکان و تجهیزات
- 📅 سیستم نوبت‌دهی آنلاین با فرم چندمرحله‌ای
- 🩺 صفحه اختصاصی هر پزشک با اطلاعات تحصیلات و سوابق
- 💊 پکیج‌های درمانی و چکاپ سلامت متنوع
- 📰 اخبار و مقالات پزشکی
- 🖼️ گالری تصاویر با فیلتر دسته‌بندی
- ❓ بخش سوالات متداول با دسته‌بندی
- 📞 فرم تماس و اطلاعات ارتباطی کامل
- 🌐 طراحی کاملاً Responsive (موبایل، تبلت، دسکتاپ)
- 🎨 تم رنگی مبتنی بر روانشناسی پزشکی (اعتماد، آرامش، شفقت)
- ⚡ Performance بالا و ساختار مناسب SEO
- 🔒 رعایت اصول امنیتی
- 🌙 پشتیبانی از حالت تاریک

## 🎨 روانشناسی طراحی

تم رنگی انتخاب‌شده بر اساس روانشناسی بازار و مشتری در حوزه پزشکی:

- **آبی پزشکی عمیق (Teal)**: حس اعتماد، حرفه‌ای‌گری و تخصص
- **سفید**: حس پاکیزگی، بهداشت و شفافیت
- **سبز ملایم (Mint)**: حس شفا، تازگی و آرامش
- **مرجانی (Coral)**: حس زندگی، انرژی و فراخوان عمل (CTA)

## 🛠️ تکنولوژی‌ها

| بخش | تکنولوژی |
|------|----------|
| Frontend | Next.js 16, React 19, TypeScript 5 |
| Styling | Tailwind CSS 4, shadcn/ui |
| Database | Prisma ORM + SQLite |
| Animations | Framer Motion |
| Icons | Lucide React |
| Forms | React Hook Form + Zod |

## 📦 نصب و اجرا

```bash
# نصب پکیج‌ها
bun install

# راه‌اندازی دیتابیس
bun run db:push
bun run scripts/seed.ts

# اجرای پروژه در محیط توسعه
bun run dev
```

سپس به `http://localhost:3000` بروید.

## 📊 مدل‌های دیتابیس

- **User** - کاربران (بیماران، پزشکان، ادمین‌ها)
- **Department** - بخش‌های درمانی
- **Doctor** - پزشکان متخصص
- **Appointment** - نوبت‌های ویزیت
- **NewsArticle** - اخبار و مقالات
- **MedicalService** - خدمات و پکیج‌های درمانی
- **MedicalDocument** - مدارک پزشکی بیماران
- **Message** - پیام‌های فرم تماس
- **Facility** - امکانات و تجهیزات
- **FaqItem** - سوالات متداول
- **GalleryItem** - آیتم‌های گالری
- **SiteSettings** - تنظیمات سایت
